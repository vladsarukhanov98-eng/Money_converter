# Конвертер валют (Money Converter)

Приложение конвертирует рубли в другие валюты с учётом региона. Так же можно посмотреть
буквенный код валюты в нужном пользователю регионе и курс валют. Оно предназначено для
людей, готовящихся к путешествию и рассчитывающих, какую сумму денег и в какой валюте им
нужно взять с собой в зависимости от выбранного региона


## Создание окружения и установка зависимостей

Проект рассчитан на работу в WSL и использует виртуальное окружение.

1. **Создай виртуальное окружение:**
    ```bash
    python -m venv .venv
    ```
2. **Активируй его:**
    ```bash
    source .venv/bin/activate
    ```
3. **Установи основные зависимости:**
    ```bash
    python -m pip install -r requirements.txt
    ```
4. **Установи зависимости для разработки и тестов:**
    ```bash
    python -m pip install -r requirements-dev.txt
    ```


## Запуск приложения

1. **В режиме разработке (с автоперезагрузкой):**
    ```bash
    python -m uvicorn money_converter:app --reload --host 0.0.0.0 --port 8000
    ```
2. **Для обычной работы:**
    ```bash
    python -m uvicorn money_converter:app --host 0.0.0.0 --port 8000
    ```
3. **После запуска открой в браузере документацию:**
    http://localhost:8000/docs


## Запуск тестов

```bash
python -m pytest -v
```


## Переменные окружения

Указаны переменные окружения с значениями по умолчанию

APP_NAME="НАЗВАНИЕ ПРИЛОЖЕНИЯ"
APP_AUTHOR="ИМЯ АВТОРА"
PORT="ИСПОЛЬЗУЕМЫЙ ПОРТ"
LOG_LEVEL=INFO


## Проверка

1. **/health:**
    ```bash
    curl http://localhost:8000/health
    ```
    В браузере: http://localhost:8000/health
2. **/version:**
    ```bash
    curl http://localhost:8000/version
    ```
    В браузере: http://localhost:8000/version
3. **Логи:**
    Логи выводятся в консоль (stdout), где запущен uvicorn. Формат строки:
    ```bash
    asctime | levelname | name | message
    ```
    При LOG_LEVEL=INFO видны события, позволяющие понять, что эндпоинт запущен, и предупреждения.
    При LOG_LEVEL=DEBUG дополнительно видны детали внутренней логики.
